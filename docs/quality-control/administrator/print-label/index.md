# 製品のラベルを印刷する

### ラベルのQRコードを作業者がiPadで読み取り、製品のチェックリストにスムーズにアクセスできるようになります。

1. [品質管理システム]トップ画面から「製品」を選択します。

    <table><tr><td>
    <img src="../../../../assets/images/quality-control/administrator/print-label/1.png" width="70%">
    </td></tr></table>

1. [製品一覧]でラベル印刷したい製品を検索してチェックボックスにチェックを入れるか全てを選択し、「ラベル印刷」を選択します。

    <table><tr><td>
    <img src="../../../../assets/images/quality-control/administrator/print-label/2.png" width="85%">
    </td></tr></table>

1. 「印刷」クリックで選択した製品のラベル印刷を行います。

    <table><tr><td>
    <img src="../../../../assets/images/quality-control/administrator/print-label/3.png" width="100%">
    </td></tr></table>

    ラベル内容

    <span style="color: #ff1493; ">①</span> 物件マスタ：名称（2行まで表示可）  
    <span style="color: #ff1493; ">②</span> 製品マスタ：製品番号（2行まで表示可）  
    <span style="color: #ff1493; ">③</span> 空欄  
    <span style="color: #ff1493; ">④</span> 製品マスタ：配筋写真撮影が空欄の場合に斜線表示  
    <span style="color: #ff1493; ">⑤</span> 製品マスタ：型枠番号（背景グレー）  
    <span style="color: #ff1493; ">⑥</span> 製品マスタ：製造ライン名称（背景グレー）  
    <span style="color: #ff1493; ">⑦</span> QRコード（mst製品：UUID）
