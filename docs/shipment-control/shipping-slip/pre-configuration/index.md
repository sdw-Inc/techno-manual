# 担当印設定

<br>

1. [品質管理システム]トップ画面から「出荷伝票」を選択します。

    <table><tr><td>
    <img src="../../../../assets/images/shipment-control/shipping-slip/pre-configuration/1.png" width="70%">
    </td></tr></table>

1. [出荷伝票用 製品一覧]画面右上の歯車マークをクリックします。

    <table><tr><td>
    <img src="../../../../assets/images/shipment-control/shipping-slip/pre-configuration/2.png" width="90%">
    </td></tr></table>

1. 出荷伝票に表示する担当印を挿入し、「登録」をクリックします。

    <table><tr><td>
    <img src="../../../../assets/images/shipment-control/shipping-slip/pre-configuration/3.png" width="50%">
    </td></tr></table>

1. 出荷伝票の[担当者]に登録した担当印が表示されます。

    <table><tr><td>
    <img src="../../../../assets/images/shipment-control/shipping-slip/pre-configuration/4.png" width="100%">
    </td></tr></table>
